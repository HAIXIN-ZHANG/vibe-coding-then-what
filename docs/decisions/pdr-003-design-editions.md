# PDR-003 · Paired editions and reading motion

Status: author-confirmed direction; paired designs and runtime checks incomplete. Decision-maker: author. Initial paired-language request predates this record; exact original date is not reconstructed. Motion/reader refinement confirmed 26 November 2026. Recorded: 26 November 2026. No runtime release is claimed.

## Context and choice

English-first project development does not mean Chinese typography can be reviewed on an English-only screen. Pair EN and ZH states at comparable viewport/text settings, group by reader journey and use English layer names and reviewer captions outside Chinese screens. Preserve meaningful technical names; ordinary interface copy follows its URL edition.

Keep neutral light/dark backgrounds with six independent accents. Use finite, restrained feedback while the reading text remains stable. Preserve native links, browser Back, focus and reduced-motion equivalents. Do not ship generated infinite-repeat animation snippets. Gesture-only chapter switching and viewport pagination remain undecided.

## Rationale and consequences

A single-language mock-up misses different wrapping and density. Decorative looping can consume attention during reading. These judgments follow author feedback and design review, not a comparative user experiment. Latin-script and Chinese designs are starting points for other languages, not certification that their font/layout needs are identical.

The current V3.1 web states still need corresponding Chinese frames and the print samples need same-content language pairs. Static frames, API-connected reactions and a browser study establish different things; none substitutes for Present/device/keyboard/storage tests. Old V1/V2/V3 comparison identities remain unchanged.
