# PDR-001 · First-volume release scope

Status: author-confirmed direction; open release conditions remain. Decision-maker: author. Confirmed/reconstructed: 26 November 2026; earlier two-book planning remains in its dated sources. Recorded: 26 November 2026. Relevant planning PR: #47 (not an implementation release).

## Context and choice

The engineering book has a complete comparison edition but new author feedback asks for technical depth and a more comfortable reader. The life book and production guide serve different purposes. Prioritise a useful, presentable first volume and its reading paths without making either later manuscript a prerequisite.

An alternative would couple all books to one launch. This comparison explains the boundary; no claim is made that a formal options workshop occurred. Independence keeps the first reader outcome reviewable while preserving later books' own schedules.

## Consequences and limits

The public label “Beta 1” is a candidate. It does not rename historical Milestone 1/Beta 1. Launch languages, whether revised web and PDF must release together, and device/acceptance scope remain open in the PRD. Existing Chinese/English availability and the 209-page PDF stay honestly identified. A new planning label does not imply an unpublished revision is live.
