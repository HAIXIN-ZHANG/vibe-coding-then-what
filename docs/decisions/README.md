# Decision records

This index contains decisions still relevant to the first volume's next public edition. PDR is our product/project decision convention; ADR may be used for a consequential engineering choice. These names are not evidence that a workflow has been generally validated. Do not create a record for every commit.

Records below were reconstructed on 26 November 2026 from author direction and identified project evidence. Where the exact original decision date is unavailable, it remains unspecified. Their acceptance status concerns the decision; it does not certify implementation. The [PRD](../product/volume-one-public-edition.md) owns open release requirements; the [board](../coordination.md) owns assignments.
