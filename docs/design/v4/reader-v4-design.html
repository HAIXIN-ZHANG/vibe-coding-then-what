Home

PRD R01, R02 and R09. The first visit shows one action; a return visit leads with Continue. The shelf is quiet: the other two books are honestly in development.

Chapter opener and reading

The core of A + B. The header is transparent at the top and gains glass once text scrolls under it. The progress hairline is 2 px brand blue. Reading time comes from the text: about 300 Chinese characters or 200 English words a minute, excluding code.

Figures, code and tables · style guide

One rule set for the book’s 19 code blocks, 14 tables and every new explanatory figure. Wells use bg-inset with radius 16 for figures and 12 for code. Captions sit below with a number per chapter (图 2-1). Figures are line-drawn SVG that recolours with the theme and stays legible in grayscale print.

Part opener and whole-book map

PRD R14. Each part starts on its own page with the opener text written on 28 November, followed by its chapter list. The map is one page, reachable from contents and every part opener; the current part is highlighted.

Contents

PRD R04 and R08. On phones it is a bottom sheet from the dock. From 1200 px it is a 300 px sidebar that pushes the column; it is closed by default and the reader may pin it, remembered on this device. Version status labels show which pieces have been revised.

Text settings

PRD R05 and R12. Inspired by Apple Books’ single “Themes & Settings” sheet: one slider and three rows of visual choices. Per-role sizes (headings, code, notes) move behind a disclosure. Changes preview live on the passage behind the sheet. Everything is saved on this device, or honestly session-only when storage is denied.

Figure view and return

PRD R06. Opening grows the figure from its inline position (300 ms); closing shrinks it back and briefly highlights the paragraph that called it (1.5 s fade). Focus returns to the expand button. With reduced motion, both directions are fades.

Search

PRD R11. Search covers only available text in the current edition. On phones it opens as a full sheet from the dock; on desktop, ⌘K or the header icon opens a centred palette (Phase 1 ships the palette look; keyboard result navigation is required).

Chapter end and reporting a problem

PRD R15 and R08. The chapter ends with a hairline, a next-chapter card, then quiet actions: previous chapter, share this section, report a problem. Reporting opens a preview of the GitHub issue draft; nothing is sent without the reader. Email waits for Phase 3.

Bookmarks

PRD R07. A bookmark is a deliberate mark on a section and is separate from the automatic Continue position. It is saved on this device only. A failed write says so and never shows a filled icon.

Page tones, dark mode and accents

PRD R12. The same chapter in three of the 24 combinations. Measured on this page’s values across all four tones, light and dark: body text 13.4:1 or higher, secondary labels 5.4:1 or higher, accent 5.4:1 or higher. T-010 re-measures from the shipped tokens. Controls stay identifiable without colour alone. Device check pending: whether serif strokes thin out in dark mode at 17 px.

English edition and switching language

PRD R08 and the AGENTS language rules. English screens pair with the Chinese ones above. Interface copy follows the URL’s edition. Moving between editions is always a deliberate action, and availability is stated plainly: two full adaptations, two overviews, and the rest in Chinese only.

Tablet and desktop panels

PRD R10. From 600 px, panels anchor to their button instead of rising from the bottom: text settings become a 360 px popover; report and bookmarks become a centred 480 px dialog; contents stays a sidebar from 1200 px. Sidebars give way before the column drops below 34em.

Failure states

PRD R05, R11 and R12, and the 320 px rule. Reading must never be blocked: a missing image, denied storage or the largest text size on the smallest phone each have a designed answer.

Empty states and errors

PRD R03 and R11. Each says what happened and offers a way on, in the book’s voice, without apology loops.
